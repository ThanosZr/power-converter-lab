# Power Converter Lab 1.0 — Κύκλωμα, ανάλυση και προσομοίωση

Τοπικό HTML/JavaScript GUI με Python + SymPy + SciPy. Υποστηρίζει ιδανικούς
buck, boost, αντιστρέφοντα buck–boost και flyback, με κοινή διαδικασία
σχεδίασης, επίλυσης, κυματομορφών και συμβολικής ανάλυσης.

## Εκκίνηση με Python

Απαιτείται Python 3.11 ή νεότερη. Αποσυμπίεσε ολόκληρο τον φάκελο,
άνοιξε terminal εκεί που βρίσκεται το `run.py` και γράψε:

```powershell
python -m pip install -r requirements.txt
python run.py
```

Η εγκατάσταση εξαρτήσεων χρειάζεται μόνο αρχικά. Μετά αρκεί `python run.py`.
Ανοίγει το http://127.0.0.1:8765. Κράτα το terminal ανοιχτό. Τερματισμός: Ctrl+C.
Αν η θύρα χρησιμοποιείται: `python run.py --port 8766`.

Μην ανοίξεις απευθείας το `web/index.html`: χρειάζεται ο τοπικός server.
Δεν απαιτούνται GPU, MATLAB, Node, εξωτερικό API ή λογαριασμός.
Τα `INSTALL.ps1` / `START.ps1` παραμένουν προαιρετικά βοηθητικά scripts.
Μπορείς επίσης να εγκαταστήσεις τις εξαρτήσεις σε δικό σου venv ή conda env.

Για αναβάθμιση, κλείσε τον παλιό server με Ctrl+C, αποσυμπίεσε το νέο
πακέτο, εκκίνησε το νέο `run.py` και κάνε Ctrl+F5 στον browser.

  τιμή σε ns), **αρχικής συνθήκης** (από μηδέν ή από το σημείο λειτουργίας)
  και **παραθύρου** παλμογράφου. Τα στοιχεία δείχνουν ζωντανά τιμές και
  ποιο άγει (S ON / D ON / iL = 0).
- Σύγκριση της τελευταίας περιόδου της προσομοίωσης με την ανάλυση.
- Οι αναλύσεις οργανώνονται σε καρτέλες: Αποτελέσματα · Σχεδίαση (BCM,

  Κυματομορφές · Επαλήθευση ODE.

## Η βασική ροή

1. Διάλεξε τοπολογία ή παράδειγμα στην επάνω μπάρα.
2. **Διπλό κλικ** σε κάθε στοιχείο για τις τιμές του:

   | Στοιχείο | Παράμετροι |
   |---|---|
   | Πηγή | Vin |
   | Διακόπτης | fs, τι ορίζεται (ρυθμιζόμενο \|Vo\| ή σταθερό D), D |
   | Πηνίο / μετασχηματιστής | L ή Lm, n = Ns/Np · γρήγορα: ½·Lcrit, Lcrit, 1,2·Lcrit |
   | Πυκνωτής | C · γρήγορα: C = Δq/ΔV για στόχο κυμάτωσης σε mV |
   | Φορτίο | μοντέλο (ωμικό / σταθερή ισχύς), \|Vo\| και Po ή R |
   | Δίοδος | ιδανική· δείχνει μέσο/RMS ρεύμα και ανάστροφη τάση |

3. Τα αποτελέσματα ενημερώνονται αυτόματα. Πάτησε **▶ Προσομοίωση**
   (ή Space) για να δεις το κύκλωμα να λειτουργεί.
4. Κάτω, στις καρτέλες, βρίσκονται οι εξισώσεις, η κυμάτωση ↔ C, οι
   χαρακτηριστικές, η συνάρτηση μεταφοράς και τα εργαλεία σχεδίασης.

### Ρυθμός και βήμα της προσομοίωσης

- **1× = 100 περίοδοι μεταγωγής ανά δευτερόλεπτο** (στα 100 kHz: 1 ms
  προσομοίωσης ανά δευτερόλεπτο). 0,1× = 10 περίοδοι/s, 0,01× = 1 περίοδος/s:
  βλέπεις τη ράμπα του ρεύματος να ανεβαίνει και τον διακόπτη να ανοίγει.
  10× είναι κατάλληλο για να δεις όλη την εκκίνηση.
- **Δt** είναι το σταθερό βήμα του ολοκληρωτή RK4. Κάθε βήμα κόβεται ακριβώς
  στις μεταβάσεις του διακόπτη (DT, T) και στο σημείο όπου μηδενίζεται το
  ρεύμα, οπότε το Δt επηρεάζει μόνο την ακρίβεια μέσα σε ένα διάστημα.
  Με T/1000 η απόκλιση από την ακριβή λύση είναι < 0,001 %· με T/50 φαίνεται
  ορατό σφάλμα, κυρίως κοντά στο BCM.
- Σε αργή κίνηση (≤ 0,05×) οι ετικέτες δείχνουν στιγμιαίες τιμές και τον
  δρόμο αγωγής· σε γρήγορη, μέσες τιμές της τελευταίας περιόδου (⌀).
- Η προσομοίωση είναι **ανοικτού βρόχου**: κρατά σταθερό το D που υπολογίστηκε.
  Από μηδενική αρχή βλέπεις την πραγματική υπερύψωση εκκίνησης χωρίς ρυθμιστή.
- Φορτίο σταθερής ισχύος: κάτω από 30 % του |Vo| συμπεριφέρεται ωμικά, γιατί το
  ιδανικό i = P/v είναι ιδιόμορφο στην εκκίνηση.

## GUI κυκλώματος

- **Διπλό κλικ** σε στοιχείο ή επιλογή + **Enter**: παράθυρο τιμών και
  αποτελεσμάτων. **Enter** εφαρμόζει, **Esc** κλείνει.
- Σύρσιμο σώματος: μετακίνηση στοιχείου. Σύρσιμο στο κενό: μετακίνηση θέας.
- Διαδοχικά κλικ σε δύο μπλε ακροδέκτες: δημιουργία καλωδίου.
- Πολλά καλώδια στον ίδιο ακροδέκτη: διακλάδωση κοινού κόμβου.
- Κλικ σε στοιχείο ή καλώδιο και **Delete**: αφαίρεση.
- **R** ή ⟳: περιστροφή. **Ctrl+Z** ή ↶: αναίρεση. ∅: κενό κύκλωμα.
- Ροδέλα: zoom. ⤢: προσαρμογή θέας. ◫: κύκλωμα και προσομοίωση
  δίπλα-δίπλα ή το ένα κάτω από το άλλο.
- **Space** (εκτός πεδίων κειμένου): εκκίνηση / παύση προσομοίωσης.

Η θέση των στοιχείων δεν αλλάζει την ηλεκτρική λύση. Οι συνδέσεις αλλάζουν
το πραγματικό γράφημα. Οι διερχόμενες γραμμές δεν ενώνονται αυτόματα:
ο ηλεκτρικός κόμβος ορίζεται από τις συνδέσεις ακροδεκτών.

Ο editor είναι ελεύθερος ως προς το σχέδιο, ενώ ο engine αναγνωρίζει τις
τέσσερις καταχωρημένες οικογένειες με ένα στοιχείο ανά ρόλο. Επιπλέον
στοιχεία, ανολοκλήρωτη καλωδίωση ή διαφορετική τοπολογία απορρίπτονται
ρητά. Δεν εφαρμόζονται οι τύποι του προηγούμενου προτύπου σε αλλαγμένο
κύκλωμα. Τα πρότυπα αποτελούν και οδηγούς σωστής σύνδεσης.

Για flyback οι τελείες έχουν σημασία: n=Ns/Np, L=Lm αναγμένο στο πρωτεύον
και iL=im αναγμένο στο πρωτεύον. Η απομονωμένη επιστροφή του δευτερεύοντος
είναι διαφορετικός κόμβος από την επιστροφή της πηγής.

## Γνωστά, άγνωστα και νόμος φορτίου

| Ορισμός προβλήματος | Δίνεις | Υπολογίζονται |
|---|---|---|
| Ρυθμιζόμενη έξοδος | Vin, στόχος \|Vo\|, Po, fs, L, C, n | Απαιτούμενο D και περιοχή αγωγής |
| Σταθερό duty + R | Vin, D, R, fs, L, C, n | Vo, Po και περιοχή αγωγής |
| Σταθερό duty + Po | Vin, D, Po, fs, L, C, n | Vo όταν υπάρχει μοναδική φυσική λύση |

Ο χαρακτηρισμός «ρυθμιζόμενη έξοδος» σημαίνει ότι λύνεται το απαιτούμενο
σημείο λειτουργίας. Δεν υπάρχει ακόμη κλειστός βρόχος ελεγκτή.
Η προσομοίωση στον χρόνο κρατά το υπολογισμένο duty σταθερό.

Με σταθερό duty και ιδανικό φορτίο σταθερής ισχύος, buck–boost/flyback σε
DCM μπορεί να μην προσδιορίζουν μοναδική έξοδο: Po=Vin²D²/(2Lfs).
Η εφαρμογή εξηγεί το πρόβλημα αντί να επιστρέψει αυθαίρετο Vo.

Όταν αλλάζουν παράμετροι ή συνδέσεις, τα παλιά αποτελέσματα ξεθωριάζουν
μέχρι να ολοκληρωθεί ο αυτόματος νέος υπολογισμός. Η απλή μετακίνηση στοιχείων
κρατά έγκυρα τα αποτελέσματα.

## Αναλυτική λύση βάσει ζητουμένου

Στην καρτέλα **Σχεδίαση → Ζητούμενο και συνθήκη** επιλέγεις:

- **L/Lm**: ελάχιστο όριο για CCM παντού, μέγιστο όριο για DCM παντού,
  min/max Lcrit ή έλεγχο αν ένα σταθερό L μπορεί να δίνει BCM παντού.
- **C**: ελάχιστο ιδανικό C για συγκεκριμένο όριο διακύμανσης τάσης.
- **Μεγέθη σημείου**: επιλεγμένα D, Io, Ipeak, Imin, Lcrit, κυμάτωση,
  RMS και καταπονήσεις ημιαγωγών, με ξεχωριστή εξίσωση ανά ζητούμενο.

Ορίζεις ένα σημείο, ένα εύρος ή δύο ανεξάρτητα εύρη. Μεταβλητές: Vin,
Vo, Po, fs, n ή, σε σταθερό duty με ωμικό φορτίο, D και R.
Το L επιτρέπεται ως άξονας όταν το ζητούμενο είναι το C.

Το εύρος αφορά όλους τους καρτεσιανούς συνδυασμούς. Για όλο το πεδίο,
ένας buck απαιτεί Vo<Vin παντού και ένας boost Vo>Vin παντού.
Αδύνατο ορθογώνιο πεδίο απορρίπτεται, αντί να αγνοηθούν οι δυσμενείς γωνίες.

### Παράδειγμα flyback — ελάχιστο L για CCM σε δύο εύρη

Δώσε Po=24 W, fs=100 kHz, n=0,5. Στη Σχεδίαση → Ζητούμενο και συνθήκη:

- Ζητούμενο L/Lm → «Ελάχιστο όριο L για CCM παντού».
- Πεδίο: δύο ανεξάρτητα μεγέθη.
- Vin=16–32 V και Vo=8–16 V.

Ο engine βρίσκει min Lcrit=13,3333 μH και max Lcrit=53,3333 μH.
Για **αυστηρή CCM παντού** απαιτείται **L>53,3333 μH**. Στην ισότητα,
το δυσμενέστερο σημείο βρίσκεται σε BCM. Με συντελεστή 1,2 προτείνεται 64 μH.

Για **DCM παντού** απαιτείται **L<13,3333 μH**. Η ισότητα πάλι δίνει BCM
στο αντίστοιχο σημείο. Ένα σταθερό L δεν μπορεί να δίνει BCM σε όλο αυτό
το μεταβαλλόμενο πεδίο. Αυτή η αδυναμία εμφανίζεται στη λύση.

Κάτω από το αποτέλεσμα εμφανίζονται: σχέση duty, συνθήκη BCM, Lcrit ως
συνάρτηση των ανεξάρτητων μεγεθών, αντικατάσταση γνωστών, παράγωγοι,
υποψήφια ακρότατα και τελική ανισότητα. Ελέγχονται κορυφές, ακμές και
εσωτερικά στάσιμα σημεία, όχι μόνο δείγματα του πλέγματος.

Ο υπολογισμός C σε δύο εύρη χρησιμοποιεί μέγιστο στο δηλωμένο πλέγμα,
με ρητή επισήμανση ότι δεν αποτελεί απόδειξη συνεχούς πολυδιάστατου ορίου.
Η ολοκλήρωση φορτίου σε κάθε σημείο ελέγχει άκρα και μηδενισμούς iC.

## Κυματομορφές, προσομοίωση και χαρακτηριστικές

Υπάρχουν δύο ανεξάρτητες λύσεις στον χρόνο:

- **Ζωντανή προσομοίωση** (δίπλα στο κύκλωμα, στον browser): σταθερό βήμα
  Δt επιλογής σου, RK4, ακριβής διάσπαση στις μεταβάσεις και στο iL = 0,
  χωρίς παραδοχή μικρής κυμάτωσης. Παλμογράφος iL/im, iS, iD, iC, |vo|, gate.
- **Επαλήθευση ODE** (καρτέλα, Python/SciPy): προσαρμοστικό βήμα, βήμα φορτίου
  στο μέσο, έλεγχος περιοδικής σύγκλισης.

Η καρτέλα **Αποτελέσματα** δείχνει τις αναλυτικές κυματομορφές μόνιμης
κατάστασης iL/im, iS, iD και |vo|.

Στις χαρακτηριστικές επιλέγεις \|Vo\|/Vin–D, Vo–D, Ipeak–D, Imin–D,
κυμάτωση–D ή Lcrit–D. Κρατούνται σταθερά η είσοδος, τα στοιχεία και η R
ή η Po ανάλογα με τον νόμο φορτίου. Η καμπύλη CCM αναφοράς είναι dashed·
η πραγματική ιδανική καμπύλη χρησιμοποιεί τον σωστό κλάδο CCM/DCM.
Τα σύνορα προκύπτουν από L=Lcrit(D). Οι τάσεις εδώ είναι μέτρα:
ο πραγματικός αντιστρέφων buck–boost έχει αρνητική έξοδο.

## Συνάρτηση μεταφοράς και symbolic

- **CCM:** δύο καταστάσεις, μέσο μοντέλο, Jacobian A/Bd, Gvd, Gvg, Bode,
  πόλοι και μηδενικά.
- **DCM:** ξεχωριστό μοντέλο χαμηλών συχνοτήτων πρώτης τάξης, από το μέσο
  ρεύμα προς την έξοδο. Το πηνίο μηδενίζεται σε κάθε περίοδο.
- **BCM:** σύνορο κλάδων· δεν επιβάλλεται μία μοναδική ομαλή Gvd ακριβώς εκεί.

Η DCM Gvd δεν είναι sampled-data μοντέλο. Ισχύει για μικρές διαταραχές που
παραμένουν σε DCM και χαμηλές συχνότητες. Το Bode περιορίζεται σε fs/20.
Για CCM χρησιμοποιείται έως fs/10. Δεν περιλαμβάνονται ESR/καθυστέρηση
PWM/νεκροί χρόνοι στις δυναμικές εξισώσεις.

Οι «Αντίστροφες σχέσεις» επιτρέπουν επίσης αλλαγή αγνώστου στις σχέσεις
κέρδους, κρίσιμης επαγωγής, κυμάτωσης, ισχύος και φορτίου. Αν λείπουν
δεδομένα, επιστρέφεται παραμετρική λύση. Δεν εκτελείται αυθαίρετος κώδικας.

## Γιατί μπορεί να μην υπάρχει DCM στον χάρτη;

Επειδή το συγκεκριμένο L/φορτίο/εύρος μπορεί να δίνει CCM παντού.
Η παλαιότερη επιλογή L/C σχεδίαζε ρητά για CCM. Ο χάρτης πλέον εξηγεί
το αποτέλεσμα, εμφανίζει εύρος Lcrit και L/Lcrit και επιτρέπει σάρωση L/C.

Το preset **Flyback · DCM** έχει Vin=24 V, Vo=12 V, Po=24 W, fs=100 kHz,
n=0,5 και Lm=10 μH. Το όριο είναι 30 μH, D=0,288675 και το μηδενικό
διάστημα είναι 42,265% της περιόδου. Με Lm=30 μH έχουμε BCM, με 100 μH CCM.

## Νέο στη 0.3 — εξισώσεις ρευμάτων και τρέχουσας κυμάτωσης

Η πράσινη περιοχή **Κυμάτωση τάσης ↔ επιλογή πυκνωτή** βρίσκεται αμέσως
κάτω από τα κύρια αποτελέσματα. Επιλέγεις:

- «Υπολόγισε την τρέχουσα κυμάτωση»: με το υπάρχον C.
- «Βρες C για μέγιστη κυμάτωση»: όριο σε Vpp, mVpp ή % του |Vo|.

Παράδειγμα flyback CCM, Vin=24 V, Vo=12 V, Po=24 W, fs=100 kHz,
n=0,5, Lm=100 μH: Io=2 A, im,min=1,4 A, im,pk=2,6 A.
Στο ON iC=−2 A· στο OFF iC=im/n−Io, δηλαδή 3,2→0,8 A.
Η ολοκλήρωση δίνει Δqpp=10 μC. Με C=100 μF η τρέχουσα κυμάτωση είναι
10 μC / 100 μF = 0,1 Vpp. Αν ζητήσεις το πολύ 0,05 Vpp,
Cmin=10 μC / 0,05 V = 200 μF.

Το «Εξισώσεις, ολοκληρώματα και αντικατάσταση» ανοίγει τις μαθηματικές
ενότητες. Περιλαμβάνονται οι τμηματικές σχέσεις iL/im, iS, iD, iC, οι μέσες
και RMS τιμές, το q(t), τα ακρότατα όπου iC=0 και ο τελικός υπολογισμός C.
Οι γενικές σχέσεις χρησιμοποιούν SI. Οι αριθμητικές τμηματικές σχέσεις
χρησιμοποιούν t_us σε μs και q_uC σε μC για ευανάγνωστους συντελεστές.

Δεν χρησιμοποιείται αδιακρίτως ο τύπος Io·D/(fs·C). Για παράδειγμα στον
ίδιο flyback με Lm=40 μH το iC αλλάζει πρόσημο και μέσα στο OFF·
το ακριβές εντός του ιδανικού μοντέλου Cmin για 0,1 Vpp είναι 104,1667 μF.

Το μαθηματικό μοντέλο και η παραγωγή Gvd/Gvg είναι πλέον ανεπτυγμένα:
KVL/KCL ανά διάστημα, μέσο μοντέλο, ισορροπία, επίλυση duty, Jacobian,
Laplace, det(sI−A), επιλογή εξόδου και τελική αριθμητική αντικατάσταση.
Για DCM παράγεται χωριστά το μέσο ρεύμα από τα τριγωνικά εμβαδά.

## Νέο στη 0.3 — αντίστροφη σχεδίαση στο όριο BCM

Η ενότητα **Σχεδίαση στο όριο BCM** βρίσκεται κάτω από τον editor και
λειτουργεί ανεξάρτητα από την τρέχουσα περιοχή αγωγής. Επιλέγεις άγνωστο:
L/Lm, Vo, Vin, fs, n ή φορτίο Po/R. Το duty λύνεται ξανά εσωτερικά.
Η τρέχουσα τιμή του επιλεγμένου αγνώστου δεν δεσμεύει τη λύση.

Με τα υπόλοιπα δεδομένα του παραπάνω flyback και δοσμένο Lm=100 μH:

- Άγνωστο Vo → Vo≈125,7267 V για BCM, νέο D≈0,9128709.
- Άγνωστο Vin, Vo=12 V → Vin≈251,4534 V για BCM, νέο D≈0,0871291.

Αυτά είναι νέα σημεία λειτουργίας, όχι αλλαγή της ετικέτας του παλιού
σημείου. Εμφανίζονται όλες οι θετικές φυσικά αποδεκτές ρίζες και κάθε
μία ελέγχεται με τον steady engine ως BCM. Όταν υπάρχουν δύο λύσεις,
μπορείς να επιλέξεις ποια θα εφαρμόσεις. Αν δεν υπάρχει λύση μεταβάλλοντας
μόνο το επιλεγμένο άγνωστο, εμφανίζεται η ασυμβατότητα.

Η δήλωση φορτίου έχει σημασία: σταθερό Po και σταθερό R είναι διαφορετικά
προβλήματα όταν ζητούμενο είναι το Vo. Το C δεν επηρεάζει το ιδανικό όριο
BCM και δεν απαιτείται να οριστεί για αυτή την αντίστροφη λύση.
